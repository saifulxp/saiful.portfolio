# Saiful Islam Portfolio — V87 Project Case Studies

V87 adds 10 individual project pages using the same Project One case-study design.

## Project pages
- project-01.html through project-10.html

## Replaceable images
Each project has its own folder:
`assets/projects/project-01/` through `assets/projects/project-10/`

Each folder contains 8 demo images named `project-XX-01.jpg` through `project-XX-08.jpg`. Replace those files with your own images while keeping the filenames, or update the image paths in the corresponding HTML file.

## Work thumbnails
Work-page thumbnails are separate in:
`assets/work-thumbnails/`

These are independent from the project case-study images.

## Navigation
All 10 Work items now open their corresponding project page. Project 01-09 link to the next case; Project 10 returns to Work.

## Contact page
- Added `contact.html`, a dedicated Contact page using the same contact/footer information and styling as the homepage.
